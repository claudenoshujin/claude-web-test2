# Claude Web 2.0

## 2.0.81 测试

- 兼容框架改用 `@layer` 固定结构层与外部主题层的优先关系，不再依赖样式节点先后顺序。
- Claude Web 自有节点使用 `all: revert-layer` 整体归零，删除逐属性防御补丁；主题换皮改走变量、标签文字和侧栏图标通道。
- 侧栏、抽屉、输入框与欢迎态增加框架背板；主题决定颜色，框架保证重新定位后的表面不透明。
- 生成器新增结构规则覆盖率断言，静态检查新增层叠边界、归零范围和防御属性回归检查。

### 兼容框架的换皮边界

兼容模式会锁定侧栏、Recents、用户区、欢迎页和输入框的结构。外部主题不能再通过这些节点的选择器改写尺寸、定位或槽位；颜色和字体应通过 `--SmartTheme*`、`--mainFontFamily` 或主题变量提供，侧栏图标仍允许使用 `background-image`、`mask-image`、伪元素 `content`，标签文字也保持可替换。`#chat` 内的真实消息正文不归零，仍由外部主题完整接管。

## 安装

安装前，先停用酒馆助手里旧的 Claude 2.0 全局脚本。两个版本同时启用会互相覆盖。

1. 打开 SillyTavern 的「扩展」面板。
2. 选择 **Install extension**。
3. 粘贴下面的仓库地址：

```text
https://github.com/claudenoshujin/claude-web-test2
```

4. 安装完成后刷新页面。

## 更新

在 SillyTavern 的 Claude Web 扩展设置里选择：

- **检查更新**：正常更新时使用
- **重新安装**：检查更新报 HTTP 500 时使用

部分环境能安装扩展，但没有可供更新接口调用的系统 Git。这时重新安装即可。主题和配色保存在浏览器的 localStorage 中，重新安装不会清除这些设置。

## 手动安装

把仓库内容完整放进：

```text
SillyTavern/public/scripts/extensions/third-party/claude-web/
```

`manifest.json` 必须位于扩展目录根部。
